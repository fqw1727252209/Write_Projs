# 在校学生个人学习规划平台 - 项目说明文档

## 一、项目概述

### 1.1 项目背景
本项目旨在为在校大学生提供一个便捷的个人学习规划管理平台，帮助学生更好地规划和管理自己的学习任务、课程安排和学习目标，提高学习效率。

### 1.2 技术架构
- **后端技术**: Spring Boot 2.7.x
- **前端技术**: Vue 3.x + Element Plus
- **架构模式**: 前后端分离
- **数据库**: MySQL 8.0
- **ORM框架**: MyBatis
- **构建工具**: Maven (后端) + npm/yarn (前端)

## 二、核心功能模块 (共7个)

### 2.1 用户管理模块
**功能描述**: 实现用户的注册、登录、个人信息管理等基础功能。

**主要功能点**:
- 用户注册 (学号、姓名、密码、专业、年级等)
- 用户登录 (学号 + 密码)
- 个人信息查看与修改
- 密码修改

**数据表**: `user` 表
- id (主键)
- student_id (学号，唯一)
- username (姓名)
- password (密码，MD5加密)
- major (专业)
- grade (年级)
- email (邮箱)
- phone (手机号)
- create_time (创建时间)
- update_time (更新时间)

---

### 2.2 学习计划管理模块
**功能描述**: 学生可以创建、查看、修改和删除自己的学习计划。

**主要功能点**:
- 创建学习计划 (计划名称、目标、开始时间、结束时间、描述)
- 查看学习计划列表 (支持按状态筛选：进行中、已完成、已过期)
- 修改学习计划
- 删除学习计划
- 标记计划完成状态

**数据表**: `study_plan` 表
- id (主键)
- user_id (用户ID，外键)
- plan_name (计划名称)
- plan_goal (计划目标)
- start_date (开始日期)
- end_date (结束日期)
- description (计划描述)
- status (状态: 0-进行中, 1-已完成, 2-已过期)
- create_time (创建时间)
- update_time (更新时间)

---

### 2.3 学习任务管理模块
**功能描述**: 将学习计划细化为具体的学习任务，方便学生进行日常管理。

**主要功能点**:
- 创建学习任务 (任务名称、所属计划、优先级、截止时间、任务内容)
- 查看任务列表 (支持按计划、优先级、状态筛选)
- 修改任务信息
- 删除任务
- 标记任务完成
- 任务进度统计

**数据表**: `study_task` 表
- id (主键)
- user_id (用户ID，外键)
- plan_id (所属计划ID，外键，可为空)
- task_name (任务名称)
- priority (优先级: 1-高, 2-中, 3-低)
- deadline (截止时间)
- content (任务内容)
- status (状态: 0-未开始, 1-进行中, 2-已完成)
- complete_time (完成时间)
- create_time (创建时间)
- update_time (更新时间)

---

### 2.4 课程表管理模块
**功能描述**: 学生可以录入和管理自己的课程表信息。

**主要功能点**:
- 添加课程 (课程名称、教师、上课时间、上课地点、学分)
- 查看课程表 (按周次展示)
- 修改课程信息
- 删除课程
- 课程表日历视图

**数据表**: `course` 表
- id (主键)
- user_id (用户ID，外键)
- course_name (课程名称)
- teacher (授课教师)
- week_day (星期几: 1-7)
- start_section (开始节次: 1-12)
- end_section (结束节次: 1-12)
- location (上课地点)
- credit (学分)
- semester (学期: 如"2024-2025-1")
- create_time (创建时间)
- update_time (更新时间)

---

### 2.5 学习统计模块
**功能描述**: 对学生的学习数据进行统计分析，以图表形式展示。

**主要功能点**:
- 计划完成率统计 (饼图)
- 任务完成情况统计 (柱状图：按周/月统计)
- 学习时长统计 (折线图)
- 课程数量统计
- 个人学习报告生成

**数据来源**: 从 `study_plan`、`study_task`、`course` 表中统计数据

---

### 2.6 学习笔记管理模块
**功能描述**: 学生可以记录学习过程中的笔记和心得体会。

**主要功能点**:
- 创建学习笔记 (标题、内容、分类、关联课程)
- 查看笔记列表 (支持按分类、课程筛选)
- 修改笔记内容
- 删除笔记
- 笔记搜索功能 (按标题或内容关键词)
- 笔记收藏功能

**数据表**: `study_note` 表
- id (主键)
- user_id (用户ID，外键)
- course_id (关联课程ID，外键，可为空)
- title (笔记标题)
- content (笔记内容，支持富文本)
- category (分类: 课堂笔记、读书笔记、心得体会等)
- is_favorite (是否收藏: 0-否, 1-是)
- create_time (创建时间)
- update_time (更新时间)

---

### 2.7 学习资源管理模块
**功能描述**: 学生可以上传和管理学习相关的资源文件。

**主要功能点**:
- 上传学习资源 (文件名、文件类型、文件大小、关联课程)
- 查看资源列表 (支持按课程、文件类型筛选)
- 下载资源文件
- 删除资源
- 资源分类管理 (课件、习题、参考资料等)
- 资源存储空间统计

**数据表**: `study_resource` 表
- id (主键)
- user_id (用户ID，外键)
- course_id (关联课程ID，外键，可为空)
- resource_name (资源名称)
- file_name (文件名)
- file_path (文件存储路径)
- file_type (文件类型: pdf、doc、ppt、视频等)
- file_size (文件大小，单位KB)
- resource_type (资源分类: 1-课件, 2-习题, 3-参考资料, 4-其他)
- download_count (下载次数)
- create_time (创建时间)
- update_time (更新时间)

## 三、数据库设计

### 3.1 数据库名称
`student_study_platform`

### 3.2 数据表汇总
1. `user` - 用户表
2. `study_plan` - 学习计划表
3. `study_task` - 学习任务表
4. `course` - 课程表
5. `study_note` - 学习笔记表
6. `study_resource` - 学习资源表

### 3.3 表关系
- `user` 与 `study_plan`: 一对多
- `user` 与 `study_task`: 一对多
- `user` 与 `course`: 一对多
- `user` 与 `study_note`: 一对多
- `user` 与 `study_resource`: 一对多
- `study_plan` 与 `study_task`: 一对多 (可选关联)
- `course` 与 `study_note`: 一对多 (可选关联)
- `course` 与 `study_resource`: 一对多 (可选关联)

## 五、项目实施计划

### 5.1 开发阶段
1. **数据库设计与创建** (1天)
2. **后端开发** (5-7天)
   - 搭建Spring Boot项目框架
   - 实现各模块的Controller、Service、Mapper
   - 配置MyBatis映射文件
   - 接口测试
3. **前端开发** (5-7天)
   - 搭建Vue项目框架
   - 实现各功能页面
   - 对接后端接口
   - 页面美化
4. **联调测试** (2-3天)
5. **文档编写** (2天)

### 5.2 预计工作量
- 总开发周期: 18-25天
- 代码量预估: 
  - 后端: 4000-5000行
  - 前端: 3000-4000行
  - SQL: 300-400行

## 六、技术实现要点

### 6.1 后端技术要点
- 使用Spring Boot快速搭建项目
- 统一返回结果封装 (Result类)
- 统一异常处理 (@ControllerAdvice)
- MyBatis实现数据持久化
- 简单的Token认证机制
- RESTful API设计

### 6.2 前端技术要点
- Vue 3 Composition API
- Element Plus UI组件库
- Axios封装HTTP请求
- Vue Router路由管理
- ECharts图表展示
- 响应式布局设计

### 6.3 数据库要点
- 合理的表结构设计
- 适当的索引优化
- 外键约束保证数据完整性
