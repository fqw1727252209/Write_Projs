### 前端代码

### 数据库

- **SQL代码**: 约300-400行

## 🎯 核心功能模块

### 1. 用户管理模块
- 文件：`UserController.java`, `UserService.java`, `Login.vue`, `Register.vue`
- 功能：用户注册、登录、个人信息管理

### 2. 学习计划管理模块
- 文件：`StudyPlanController.java`, `StudyPlanService.java`, `Plan.vue`
- 功能：创建、查看、修改、删除学习计划

### 3. 学习任务管理模块
- 文件：`StudyTaskController.java`, `StudyTaskService.java`, `Task.vue`
- 功能：创建、查看、修改、删除学习任务

### 4. 课程表管理模块
- 文件：`CourseController.java`, `CourseService.java`, `Course.vue`
- 功能：添加、查看、修改、删除课程

### 5. 学习笔记管理模块
- 文件：`StudyNoteController.java`, `StudyNoteService.java`, `Note.vue`
- 功能：创建、查看、搜索、修改、删除笔记

### 6. 学习资源管理模块
- 文件：`StudyResourceController.java`, `StudyResourceService.java`, `Resource.vue`
- 功能：上传、下载、管理学习资源文件

### 7. 学习统计模块
- 文件：`StatisticsController.java`, `StatisticsService.java`, `Statistics.vue`
- 功能：数据统计、图表展示

## 🚀 快速开始

1. **数据库初始化**
   ```bash
   cd sql
   mysql -uroot -proot < create_database.sql
   mysql -uroot -proot < create_tables.sql
   mysql -uroot -proot < init_data.sql
   ```

2. **启动后端**
   ```bash
   cd backend
   mvn spring-boot:run
   ```

3. **启动前端**
   ```bash
   cd frontend
   npm install
   npm run dev
   ```

4. **访问系统**
   - 前端地址：http://localhost:5173
   - 后端地址：http://localhost:8080/api
   - 测试账号：学号 `2021001`，密码 `123456`
