# 在校学生个人学习规划平台 - 接口文档

## 基本信息

- **Base URL**: `http://localhost:8080/api`
- **数据格式**: JSON
- **字符编码**: UTF-8

## 统一返回格式

```json
{
  "code": 200,
  "message": "操作成功",
  "data": {}
}
```

**说明：**
- `code`: 状态码，200表示成功，500表示失败
- `message`: 返回消息
- `data`: 返回数据

---

## 1. 用户管理接口

### 1.1 用户注册

**接口地址**: `/user/register`  
**请求方式**: POST  
**请求参数**:

```json
{
  "studentId": "2021001",
  "username": "张三",
  "password": "123456",
  "major": "计算机科学与技术",
  "grade": "2021级",
  "email": "zhangsan@example.com",
  "phone": "13800138000"
}
```

**返回示例**:

```json
{
  "code": 200,
  "message": "注册成功",
  "data": null
}
```

### 1.2 用户登录

**接口地址**: `/user/login`  
**请求方式**: POST  
**请求参数**:

```json
{
  "studentId": "2021001",
  "password": "123456"
}
```

**返回示例**:

```json
{
  "code": 200,
  "message": "登录成功",
  "data": {
    "id": 1,
    "studentId": "2021001",
    "username": "张三",
    "major": "计算机科学与技术",
    "grade": "2021级",
    "email": "zhangsan@example.com",
    "phone": "13800138000"
  }
}
```

### 1.3 获取用户信息

**接口地址**: `/user/{id}`  
**请求方式**: GET  
**路径参数**: id - 用户ID

### 1.4 更新用户信息

**接口地址**: `/user/update`  
**请求方式**: PUT  
**请求参数**: User对象

### 1.5 修改密码

**接口地址**: `/user/password`  
**请求方式**: PUT  
**请求参数**: 
- userId: 用户ID
- oldPassword: 原密码
- newPassword: 新密码

## 2. 学习计划接口

### 2.1 创建学习计划

**接口地址**: `/plan/create`  
**请求方式**: POST  
**请求参数**:

```json
{
  "userId": 1,
  "planName": "英语四级备考计划",
  "planGoal": "通过英语四级考试",
  "startDate": "2024-09-01",
  "endDate": "2024-12-15",
  "description": "每天背单词100个",
  "status": 0
}
```

### 2.2 获取学习计划列表

**接口地址**: `/plan/list`  
**请求方式**: GET  
**请求参数**: 
- userId: 用户ID（必填）
- status: 状态（可选，0-进行中，1-已完成，2-已过期）

### 2.3 获取学习计划详情

**接口地址**: `/plan/{id}`  
**请求方式**: GET

### 2.4 更新学习计划

**接口地址**: `/plan/update`  
**请求方式**: PUT

### 2.5 删除学习计划

**接口地址**: `/plan/{id}`  
**请求方式**: DELETE

### 3.2 获取学习任务列表

**请求参数**: 
- userId: 用户ID（必填）

### 3.3 更新学习任务

**接口地址**: `/task/update`

### 3.4 删除学习任务

## 6. 学习资源接口

### 6.1 上传资源

**接口地址**: `/resource/upload`  
**请求方式**: POST  
**Content-Type**: multipart/form-data  
**请求参数**: 
- file: 文件
- userId: 用户ID
- courseId: 课程ID（可选）
- resourceName: 资源名称
- resourceType: 资源类型（1-课件，2-习题，3-参考资料，4-其他）

### 6.2 获取资源列表

**接口地址**: `/resource/list`  
**请求方式**: GET  
**请求参数**: 
- userId: 用户ID（必填）
- courseId: 课程ID（可选）
- resourceType: 资源类型（可选）

### 6.3 下载资源

**接口地址**: `/resource/download/{id}`  
**请求方式**: POST  
**说明**: 增加下载次数

## 注意事项

1. 所有日期时间格式为：`yyyy-MM-dd HH:mm:ss`
2. 日期格式为：`yyyy-MM-dd`
3. 密码在传输前会进行MD5加密
4. 文件上传大小限制为50MB
