## 环境要求

### 必需软件
- **JDK**: 1.8 或以上
- **Maven**: 3.6 或以上
- **Node.js**: 16.x 或以上
- **MySQL**: 8.0 或以上

### 推荐配置
- **操作系统**: Windows 10/11, Linux, macOS
- **内存**: 4GB 以上
- **硬盘**: 10GB 可用空间

## 数据库部署

### 步骤1：启动MySQL服务

**Windows:**
```bash
# 打开服务管理器，启动MySQL服务
# 或使用命令行
net start MySQL80
```

**Linux/Mac:**
```bash
sudo service mysql start
# 或
sudo systemctl start mysql
```

### 步骤2：执行SQL脚本

进入项目的 `sql` 目录，按顺序执行以下脚本：

```bash
# 方法1：命令行执行（推荐）
cd sql
mysql -uroot -proot < create_database.sql
mysql -uroot -proot < create_tables.sql
mysql -uroot -proot < init_data.sql
```

或者：

```bash
# 方法2：登录MySQL后执行
mysql -uroot -proot
mysql> source create_database.sql;
mysql> source create_tables.sql;
mysql> source init_data.sql;
mysql> exit;
```

### 步骤3：验证数据库

```sql
mysql -uroot -proot
use student_study_platform;
show tables;
-- 应该看到6张表：user, study_plan, study_task, course, study_note, study_resource
```

## 后端部署

### 步骤1：配置数据库连接

打开 `backend/src/main/resources/application-dev.yml`，确认配置：

```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/student_study_platform?useUnicode=true&characterEncoding=utf8&useSSL=false&serverTimezone=Asia/Shanghai
    username: root
    password: root  # 修改为你的MySQL密码
```

### 步骤2：创建文件上传目录

**Windows:**
```bash
# 创建目录
mkdir D:\upload
```

**Linux/Mac:**
```bash
# 创建目录并设置权限
sudo mkdir -p /var/upload
sudo chmod 777 /var/upload
```

如果使用Linux/Mac，需要修改 `application.yml` 中的上传路径：
```yaml
file:
  upload-path: /var/upload/
```

### 步骤3：编译并启动后端

```bash
# 进入后端目录
cd backend

# 清理并安装依赖
mvn clean install

# 启动项目
mvn spring-boot:run
```

或者使用IDE（如IntelliJ IDEA）：
1. 打开 `backend` 目录
2. 找到 `PlatformApplication.java`
3. 右键 -> Run 'PlatformApplication'

### 步骤4：验证后端启动

看到以下日志说明启动成功：
```
========================================
   学生学习规划平台启动成功！
   访问地址: http://localhost:8080/api
========================================
```

测试接口：
```bash
# 在浏览器或Postman中访问
http://localhost:8080/api/user/1
```

## 前端部署

### 步骤1：安装依赖

```bash
# 进入前端目录
cd frontend

# 安装依赖（首次运行）
npm install

# 如果速度慢，使用淘宝镜像
npm install --registry=https://registry.npmmirror.com
```

### 步骤2：启动开发服务器

```bash
npm run dev
```

### 步骤3：访问前端页面

看到以下信息说明启动成功：
```

➜  Local:   http://localhost:5173/
➜  Network: use --host to expose
```

## 生产环境部署

### 后端打包

```bash
cd backend
mvn clean package

# 生成的jar包在 target 目录下
# student-study-platform-1.0.0.jar

# 运行jar包
java -jar target/student-study-platform-1.0.0.jar
```

### 前端打包

```bash
cd frontend
npm run build

# 生成的静态文件在 dist 目录下
# 将 dist 目录部署到 Nginx 或其他Web服务器
```

### Nginx配置示例

```nginx
server {
    listen 80;
    server_name your-domain.com;

    # 前端静态文件
    location / {
        root /path/to/frontend/dist;
        index index.html;
        try_files $uri $uri/ /index.html;
    }

    # 后端API代理
    location /api {
        proxy_pass http://localhost:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

## 常见问题

### 1. 后端启动失败

**问题：端口被占用**
```
Port 8080 was already in use
```
**解决方法：**
- 修改 `application-dev.yml` 中的端口号
- 或者关闭占用8080端口的程序

**问题：数据库连接失败**
```
Cannot connect to database
```
**解决方法：**
- 检查MySQL服务是否启动
- 检查用户名密码是否正确
- 检查数据库是否已创建

### 2. 前端启动失败

**问题：依赖安装失败**
```
npm ERR! code ECONNREFUSED
```
**解决方法：**
```bash
# 使用淘宝镜像
npm install --registry=https://registry.npmmirror.com

# 或者使用cnpm
npm install -g cnpm --registry=https://registry.npmmirror.com
cnpm install
```

**问题：端口被占用**
```
Port 5173 is already in use
```
**解决方法：**
- Vite会自动使用下一个可用端口
- 或在 `vite.config.js` 中修改端口

### 3. 跨域问题

如果前端访问后端出现跨域错误：
- 检查后端 `CorsConfig.java` 配置
- 确保前端的API请求地址正确

### 4. 文件上传失败

**解决方法：**
- 确保上传目录存在且有写入权限
- Windows: `D:/upload/`
- Linux/Mac: `/var/upload/`（需要777权限）

### 5. 登录失败

**问题：学号不存在或密码错误**
**解决方法：**
- 确认已执行 `init_data.sql` 初始化数据
- 使用测试账号：学号 `2021001`，密码 `123456`
- 或重新注册新账号

## 开发模式 vs 生产模式

### 开发模式
- 后端：`mvn spring-boot:run`（端口8080）
- 前端：`npm run dev`（端口5173）
- 前端通过Vite代理访问后端

### 生产模式
- 后端：`java -jar xxx.jar`
- 前端：打包后部署到Nginx
- 通过Nginx反向代理访问后端
